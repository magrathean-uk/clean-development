# Clean Development 0.6.1+ commands

Only when `clean-development version` reports 0.6.1 or later.

(0.6.1+) Path leases protect scratch, build and cache paths across long or quiet jobs and parent-child handoffs:

```sh
clean-development leases create --path "$CLEAN_DEV_SCRATCH" --path "$CLEAN_DEV_BUILDS" --minutes 60 --owner 'job description' --apply
clean-development leases renew LEASE_ID --minutes 60 --apply
clean-development leases release LEASE_ID --apply
```

Leases protect cleanup only; they do not supervise or keep processes alive. Renew them before expiry (1-1440 minutes) and release them after the consumers finish. (0.6.1+) `publish --source FILE --destination /durable/FILE --apply` publishes one regular file with verification and no clobbering.
