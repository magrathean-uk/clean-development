# Support

Use [GitHub Issues](https://github.com/magrathean-uk/clean-development/issues) for public, reproducible bugs and focused feature requests. Remove credentials, private repository names, full command histories, prompts, and agent transcripts. Include sanitized `clean-development status --json` and `clean-development doctor --json` output when it helps reproduce a problem.

GitHub Discussions are not enabled for this repository at the reviewed time. If they are enabled later, use them for setup questions and design conversations.

Do not use public issues or discussions for vulnerabilities or sensitive conduct reports. Use the published email route in [SECURITY.md](https://github.com/magrathean-uk/clean-development/blob/main/SECURITY.md) for vulnerabilities. For conduct concerns, follow the separate initial-contact guidance in [CODE_OF_CONDUCT.md](https://github.com/magrathean-uk/clean-development/blob/main/CODE_OF_CONDUCT.md).

This is a community open-source project. It does not state a response-time commitment or commercial support agreement.
