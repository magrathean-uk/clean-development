# Code, design, and general inspection — 26 September 2026

Reviewed the CLI, configuration and session API, storage ownership and pruning, runtime and adapters, native integrations, distribution metadata, test harnesses, and documentation. This is a command-line product; the design review covered command discovery, consent choices, failure messages, and diagnostic accuracy.

## Findings and fixes

| Finding | Fix and regression coverage |
| --- | --- |
| `doctor` returned success after a managed cache directory was removed and trusted runtime receipt metadata without checking installed files. | Inspect all managed bases and verify runtime inventories, ownership, permissions, and recorded Node availability without repairing anything. Test missing directories, non-directory paths, and a missing launcher. |
| Direct callers of `applySessionPlan` could create storage despite `enabled: false`, and skip retained cache variables injected by an outer session. | Return skip for a disabled plan and clear unchanged inherited routing. Exercise both routed modes, verify that no managed directories appear, and retain explicit user overrides. |
| `init` checked for an existing file before using a replacing write, leaving a race with another creator. | Use exclusive creation unless replacement is explicitly forced. Simulate another file appearing after the existence check and verify its original bytes survive. |
| Corrupt state interrupted inspection; prune's apply phase did not fully revalidate receipt shape or its age threshold. | Retain untrusted ownership state, conservatively protect a workspace whose lease cannot be validated, and check the current receipt and timestamp before deletion. Test corrupt markers, receipts, leases, and invalid prune thresholds. |
| Cargo routing read internal environment markers case-sensitively despite case-insensitive environment handling elsewhere. | Normalize marker reads and writes. Test that a nested workspace receives its own target and one canonical set of markers. |
| Native Claude setup omitted fork sessions supported by the bundled hook. | Include `fork` in the matcher. Verify setup/uninstall retain unrelated hooks. |
| Per-command help failed, the interactive default was implicit, and invalid environment formats silently produced shell output. An empty comma-separated agent list was also accepted. | Support command help without intercepting child help, label the default choice, and reject invalid selections before writes. |

## Design and architecture assessment

The existing separation of configuration, session decisions, tool adapters, runtime installation, and owned storage is appropriate for this package. Preserve the explicit consent modes, dry-run-first pruning, environment override precedence, and receipt-based removal model. No graphical interface or new abstraction layer is needed.

The diagnostic and help fixes make the main workflow easier to understand: inspect the session plan, choose a mode, run the tool, and diagnose the actual installed state. Existing JSON output remains available for automation. No automatic cleanup, dependency, telemetry, or host configuration migration was added.

## Validation and limits

Current verification results are recorded in [verification.md](verification.md). Tests use disposable homes, agent settings, and artifact roots. The review did not alter installed agent settings or existing user build storage.

Real host acceptance and native Windows execution remain separate from source review and isolated tests. The historical v0.2.0 package hashes and host observations do not certify these unreleased fixes; see the existing acceptance limitations in the verification document.
