# Code of conduct

Clean Development should be a practical, welcoming project.

Be respectful, assume good faith, keep criticism about the work, and make room for people with different experience levels and backgrounds. Harassment, threats, personal attacks, discrimination, doxxing, sexualized conduct, and sustained disruption are not accepted in project spaces.

Maintainers may edit or remove contributions and restrict participation when needed to protect the community. Enforcement should consider context, impact, prior behavior, and a proportionate path back where appropriate.

For ordinary moderation, contact the repository maintainers. For a sensitive concern, use [contact@magrathean.uk](mailto:contact@magrathean.uk), the general contact address published in the [Magrathean UK security policy](https://github.com/magrathean-uk/.github/blob/main/SECURITY.md), to request a confidential reporting channel. Send only enough information to arrange that channel; do not include sensitive personal details until the recipient confirms how to share them privately. This address is not verified as a dedicated conduct-reporting inbox.

Do not publish personal details in an issue. Good-faith reports will be handled as privately as the platform allows. Retaliation against a reporter is not accepted.

This policy applies in repository discussions, issues, pull requests, community spaces, and when someone officially represents the project.
